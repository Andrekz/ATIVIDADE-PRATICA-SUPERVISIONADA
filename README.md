# Classe Fila

Responsável por controlar a ordem de atendimento dos clientes.

Atributos:

inicio: aponta para o primeiro cliente da fila.

fim: aponta para o último cliente inserido.

Principais métodos:

inserir(Elemento e): adiciona um novo cliente ao final da fila.

remover(): remove o cliente no início (próximo a ser atendido).

vazia(): verifica se a fila está vazia.

exibirFila(): mostra toda a ordem atual de atendimento.



# Classe Pilha

Controla o histórico de solicitações.

Atributos:

topo: aponta para o elemento mais recente inserido.

Principais métodos:

inserir(Elemento e): adiciona uma nova solicitação no topo.

remover(): retira a solicitação mais recente (última adicionada).

vazia(): verifica se o histórico está vazio.

exibirPilha(): mostra todas as solicitações registradas.
